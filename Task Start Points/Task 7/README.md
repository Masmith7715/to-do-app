# To-Do-List App

A clean, responsive, and feature-rich To-Do-List application built with vanilla HTML, CSS, and JavaScript. Designed with LocalStorage persistence, task completion toggling, and task management capabilities.

## Purpose
This project demonstrates modern web development principles, DOM manipulation, event handling, browser storage persistence, and AI-driven development workflows using GitHub Copilot.

## Features
- **Add Tasks**: Quickly add new tasks via input text box or pressing the Enter key.
- **Mark as Complete**: Click on any task text to toggle its completion status with a visual strikethrough.
- **Delete Tasks**: Remove unwanted tasks instantly using the delete button.
- **LocalStorage Persistence**: Tasks and their completion states are automatically saved to the browser's LocalStorage so they persist across page reloads.
- **Clean UI**: Modern, responsive design with smooth hover effects and intuitive layout.

## Usage
1. Open `index.html` in your browser or run via Live Server (Port 5500).
2. Type a task name into the input field and click **Add Task** (or press Enter).
3. Click on the task text to mark it complete / incomplete.
4. Click **Delete** to remove a task from the list.
